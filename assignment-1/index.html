Inline CSS, Internal CSS and External CSS

CSS stands for Cascading Style Sheets, a fundamental stylesheet language used to describe the presentation, layout, and visual formatting of documents written in a markup language like HTML or XML. Alongside HTML and JavaScript, CSS forms the core triad of languages powering the World Wide Web. It is managed and standardized globally by the World Wide Web Consortium (W3C).
